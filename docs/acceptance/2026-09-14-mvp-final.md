## 前后端会话数据边界

本项目 Web 不承载 assistant-ui 会话，也没有 `ExternalStoreRuntime` 会话数据；前端只消费后台服务提供的 REST DTO，权威业务状态始终由后台 `RuntimeRepository` 管理。因此本工单不存在把后端会话对象直接放入前端 Runtime 的例外，也不影响最终交付。
