# 使用一个版本化的综合价值分

qiushui-airadar 不再分别展示内容价值和个人相关度，而是让模型按 1–5 档输出主题匹配、实质性、可信度、新颖性、可操作性、工作价值和清晰完整性，TypeScript 再按版本化权重计算唯一的 0–100 综合价值分。这样列表只有一个容易理解的总分，同时仍可在明细中解释内容质量和对秋水的实际价值。

初始权重依次为 20%、15%、15%、10%、15%、15%、10%；核心精选要求总分至少 80、主题匹配为 5、实质性和可信度至少为 3，探索候选要求总分至少 60、主题匹配至少为 4、实质性和可信度至少为 3。平台、信源、博主、篇幅、内容形态和互动数据不提供额外加成；命中画像排除清单或有效垃圾分类时，不具备推荐资格。分项、定义、权重、阈值和门槛后期均可在 Web 中配置，每次保存生成不可变评分规则版本且启用权重总和必须为 100%，只影响之后的分析。

AI 和秋水都可以标记带分类的垃圾，AI 判断无需确认即可立即生效，但页面必须显示来源，人工修改始终拥有最终优先级。AI 自己的判断不作为训练真值；本期保存人工标记和纠正样本，后期由 AI 提出评分策略调整方案，仍须秋水确认后才能启用。
